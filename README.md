# The one-line excuse

A program that writes one short text for make.fun's bounty `u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`: the excuse an AI gives its human for missing a deadline, judged two at a time for the funniest, freshest one. `main.py` holds the line as a single constant and writes it to `entry.txt` in the folder named by `MAKEFUN_OUTPUT_DIR` (or `/output`), with no trailing newline.
